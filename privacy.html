家計簿 隱私權政策

最後更新：2026 年 11 月 21 日

這是什麼

「家計簿」是張家自用的家庭記帳工具，不對外提供服務，使用者只有擁有者本人。

存取哪些資料、用來做什麼

  • Google 試算表：讀取與寫入擁有者自己的家計簿試算表，用來記帳、顯示預算與圖表。
  • Google 雲端硬碟：在擁有者的雲端硬碟建立試算表備份。
  • Apps Script 專案與部署：從本專案的 GitHub 原始碼更新擁有者自己的 Apps Script 後端。
  • 觸發器與外部請求：排程備份，以及讀取本專案在 GitHub 上的公開原始碼。

資料存在哪裡、會不會分享

  • 記帳資料只存在擁有者自己的 Google 帳號（試算表與雲端硬碟）中。
  • 本工具不會把資料傳送、出售或分享給任何第三方，也不使用廣告或追蹤分析。
  • 手機端只在瀏覽器的本機儲存空間保存連線設定與上次畫面的暫存資料，不會上傳到其他地方。

如何停止授權

擁有者可隨時到 Google 帳戶的「安全性 → 具有帳戶存取權的第三方應用程式」移除本工具的存取權。
